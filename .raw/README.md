# Raw inputs

This folder holds original, immutable source material for the CRO seat: client-supplied
files, exported reports, screenshots, or other inputs an agent receives but does not author.

Rules:

- Never edit a file placed here. If a source needs correcting, replace it and note why in
  the commit message, do not patch it in place.
- Never treat a file in this folder as a wiki note. It is not linted, not tagged, and not
  part of the front matter schema described in `wiki/index.md`.
- When a file lands here, the agent that placed it records its existence, source, and date
  in the relevant wiki entity page or in `wiki/cadence.md`, so the wiki stays the pointer
  layer and this folder stays the archive.

This folder is empty at the moment this convention was written. It fills as raw material
actually arrives.
